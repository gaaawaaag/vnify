# 人物与地点差分（Variants）

人物与地点均支持配置多套可见状态（**差分**），用于表现剧情推进中的服装更换、受伤、伪装揭示、年龄跨度，或地点的昼夜、天气、灾后变化。差分定义与触发范围保存在导演记录中，正文脚本无需插入差分标记。

---

## 核心概念

| 概念 | 说明 |
| --- | --- |
| 默认图 | 人物的初始立绘或地点的默认主图；无差分状态记录或差分未绑定图片时自动使用 |
| 差分定义（`variants`） | 描述实体的另一套完整可见状态（`{id, entityId, name, reason, ...}`），每个差分对应一张独立图片 |
| 状态记录（`states`） | 指定某实体在一段正文单元范围内使用的差分（`variant`）或人物舞台在场状态（`present`） |

涉及伪装或身份揭示的人物，以读者最先见到的形象作为默认图，揭示后的真实形象登记为差分，从而保证早期阅读与人物档案不会提前暴露后续形象。

---

## 差分定义（`variants`）

差分在首次使用的章节导演记录（或全书设计 `design.json`）中定义，后续章节复用时直接通过状态记录引用其 `id`：

```json
"variants": [
  {
    "id": "lin.injured",
    "entityId": "lin",
    "name": "受伤",
    "reason": "第三章起额头包扎、外套破损，持续多章。",
    "face": "A white bandage wrapped around his forehead, slight bruises on his cheek.",
    "body": "Wearing a torn blue cotton shirt with dust on the sleeves, standing with his left hand supporting his right arm."
  },
  {
    "id": "old_station.night",
    "entityId": "old_station",
    "name": "雨夜",
    "reason": "暴雨夜间的旧车站站台。",
    "prompt": "The old train station platform at night in heavy rain, dim yellow lamps reflecting on wet stone."
  }
]
```

- **标识符（`id`）**：全书唯一，匹配 `[\w.-]{1,160}`。全书设计中预登记的差分可自由命名（如 `lin.injured`）；章节导演新增的局部差分以 `<章节ID>.` 开头（如 `ch03.lin.injured`）。
- **人物差分字段**：填写 `face` 和／或 `body` 的覆盖描述，省略的字段自动沿用该人物的默认设计；可选填写 `stature`（`0.7`–`1.1`），用于童年等身高变化的差分形象。每个人物差分生成一张 `2:3` 透明立绘，对话框头像从该立绘自动裁切。
- **地点差分字段**：填写完整的 `prompt` 画面描述，保持与地点默认主图一致的空间结构。
- **显示名称（`name`）**：用于资产管理器与图集展示（如“受伤”“雨夜”）。

## 状态记录（`states`）

章节导演记录中的 `states` 数组控制人物与地点在具体正文位置的状态切换：

```json
"states": [
  {"entityId": "lin", "from": "s01:3", "variant": "lin.injured"},
  {"entityId": "lin", "from": "s02:1", "to": "s02:9", "variant": "ch03.lin.coat"},
  {"entityId": "lin", "from": "s04:1", "variant": null},
  {"entityId": "chen", "from": "s01:1", "to": "s01:6", "present": true}
]
```

### 持续记录与区间记录

每条状态记录以本章的正文单元 ID 作为起点 `from`，按是否包含终点 `to` 分为两类：

- **持续记录（省略 `to`）**：从 `from` 起生效并跨章延续，直至该实体的下一条持续记录。将 `variant` 设为 `null` 表示恢复默认图。适用于年龄变化、长期换装、受伤、建筑损毁等跨越多场的持续状态。
- **区间记录（包含 `to`）**：仅在本章 `[from, to]`（含首尾）范围内生效，离开区间后自动恢复为当时的持续状态。同一实体在同一章内的区间记录互不重叠。适用于单场戏的临时换装、雨夜或短暂的强烈情绪状态。

任意阅读位置的生效状态优先级为：**覆盖当前单元的区间记录 → 当前位置之前最近的一条持续记录 → 默认状态**。地点差分的状态记录仅作用于当前有效地点为该地点的场景单元。

### 人物舞台在场状态（`present`）

在开启人物立绘的 `scene` 场景中，人物进出现场由导演在 `states` 中用 `present` 写明；播放器据此并按对话决定显示谁：人物开口（对白或心声）时上场，最近 4 轮对话（同一人连续的台词算一轮）里说过话的人留在台上，更久没开口的在别人开口时退场；连续三屏以上的旁白都没提到台上的人时清场；同屏站满时最久没说话的人让位。播放器只看已读到的内容，不往后看。`present` 的写法如下（`present` 与 `variant` 各自独立计算时间线，可写在同一条记录或分开书写）：

- **区间 `present: true`（包含 `to`）**：让人物在 `[from, to]` 期间站在画面上，适用于场中推门进入现场、尚未开口已在场的人物；台上站满时，此人与其他人一样会让位给开口的人，之后只在有空位时回来，不会逐句挤掉正在对话的人。
- **区间 `present: false`（包含 `to`）**：让人物在 `[from, to]` 期间不显示立绘（发言时仅在对话框旁显示头像），适用于中途离场、隔门交谈或通过电话发言的人物。
- **持续 `present: false`（省略 `to`）**：从 `from` 起跨章持续不显示舞台立绘，适用于第一人称视角叙述者或仅以声音登场的人物。
- **持续 `present: true`（省略 `to`）**：解除此前的持续不上场状态，交回默认自动上下场规则。

### 镜头区间（`stages`）

规则排出的画面与原文段落不合时，导演在章节记录的 `stages` 中直接指定一段画面上站的人物（开启人物立绘时才写，没有则省略）：

```json
"stages": [
  {"from": "s01:4", "to": "s01:9", "cast": ["chen"]}
]
```

- `from`、`to` 位于本章同一个 `scene` 内，同章的区间互不重叠；`cast` 为 0—3 个人物 ID，按从左到右的顺序。
- 范围内画面上只有 `cast` 中的人物（`present: false` 的人物与没有立绘、尚未公开的人物除外），从 `from` 起即站在画面上；`cast` 以外的人物说话时按画面外显示头像。窄屏站不下时保留正在说话与最近说过话的人。范围结束后从这份名单接着按自动上下场规则。
- 常见用途：以几屏篇幅专写一位人物的外貌或来历时只留此人；人多的场面中两三人的持续对话；在场却不开口的人物；全景或人群段落清空舞台（`cast: []`）。

## 数量上限与资产绑定

### 数量上限

在开启 `characterVariants` 或 `locationVariants` 时，工具对单实体的差分数量执行上限检查（默认图不计入）：
- **主要人物**（全书设计中标记 `main: true`）：每人最多 **4** 个差分。
- **其他人物**：每人最多 **1** 个差分。
- **地点**：每个地点最多 **2** 个差分。

### 生图与作品包绑定

- **生图任务**：差分任务在对应实体的默认图完成绑定后激活，同时提供基于默认图的图像编辑提示词（`editPrompt` + `referenceFile`）与完整文生图提示词（`prompt`）。
- **资产清单结构**：
  - 人物差分绑定于角色图片清单（v5）的 `characterImages.bindings[人物ID].variants[差分ID]`，结构与默认立绘相同（含 `imageId`、可选 `flip` 与 `crop`）。
  - 地点差分绑定于背景资产清单（v8）的 `backgrounds.bindings.variants[差分ID]`。
- **回退规则**：当某个差分尚未绑定图片时，播放器自动回退显示该人物或地点的默认图。

示例见 [examples/variants.vn.txt](../examples/variants.vn.txt)。
