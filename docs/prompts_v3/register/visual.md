## 外观参考

visual-profiles.json 收集原文对人物和地点外观的描写。它是一个数组，原文有外观描写的人物和地点各一条：

```json
[{"id":"lin","look":[
  {"source":"p000003","text":"一头及肩的黑发被雨打湿，贴在瘦削的肩上"},
  {"source":"p000140","text":"十岁的她剪着男孩似的短发","when":"回忆，十岁"}
]}]
```

`look` 的每一项是一处描写：

- `source`：这处描写所在的来源编号。
- `text`：从该来源中原样摘出的文字，一字不改，取写到外观的那半句或一两句。同一来源里隔开的两处描写分成两项。
- `when`：这处描写不是主要故事时段的通常样子时填写，用几个字写明时期或场合，如“回忆，十岁”“葬礼上”“淋雨后”；通常样子不写这一项。

摘录的内容：

- 人物：年龄、发型发色、瞳色、肤色、身高体型、五官，眼镜、胡须、伤疤、眼罩等标志性特征，服装与随身物。
- 地点：空间与布局、建筑、材质、陈设。

同一对象在全书各处的描写都摘，前后说法不同的都保留。一句话写到几个人时，在每个人的条目下各摘与此人有关的部分。只写一时神情或动作的句子不摘。原文没有外观描写的对象不列条目，全书都没有时文件写 `[]`。只负责一段时，只摘本段里的描写。转换中读到尚未收录的外观描写，按同样格式补入。

用户指定的外观，以及参考图说明里的外观，不是原文句子：写在该对象条目的 `note` 里（一段文字，可与 `look` 并存），如 `{"id":"lin","note":"用户指定：左眼下有一颗痣"}`。
