# G4 · register/passages

正式开发模块。仅标记内的文字属于提示词。

## register.disclosure

<!-- prompt:register.disclosure -->
## 公开节点

列出转换时不能提前透露的信息，每条写来源编号与做法：身份延后揭示的人物在揭示前用什么称呼或 guest、叙述者在哪里自报姓名、称呼在哪里改变、真相或凶手在哪里揭晓。只列原文确实延后揭示的事。
<!-- /prompt -->

## register.passages

<!-- prompt:register.passages -->
## 特殊段落

只列读过原文才能判断、转换时需要特别处理的位置，每条一行，写来源编号与结论：

- 引用材料：信件、公告、报道、日记、诗歌、题记等需要整体呈现的内容，注明 message 或 verse。
- 回忆与复述：回忆、梦境，以及人物较详细地复述过去场面（有经过并有两句以上原话）的范围与复述者。
- 说话人：没有说话提示、容易归错的对白，写判断的说话人和一句依据。说话人一读就清楚的不列。
- 分隔行：独占一行的 `*`、`***`、`————` 等。
<!-- /prompt -->

## register.annotations

<!-- prompt:register.annotations -->
## 原书注解

能确认的原注每条一行：注解所在的来源（含续注）、引用它的来源、被解释的词语。原注包括“（注：……）”“（译者注：……）”等内嵌注，以及页末、章末、篇末注；内嵌注的两处编号可以相同。编号逐页或逐章重新起算时，结合当地上下文对应。找不到明确引用位置的注解不列，其来源照常按正文处理。
<!-- /prompt -->

## register.typos

<!-- prompt:register.typos -->
## 错字

能从上下文确定原意的输入或识别错字（形近、同音、漏字、多字），每条一行：来源编号、原文、订正；同一错字在多处出现时写在一行并列出全部编号。拿不准的标“存疑”，转换时照录。
<!-- /prompt -->
