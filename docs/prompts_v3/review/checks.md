## 核对与修复范围

- 按来源核对实际文字，检查明确的漏文、误增、重复拼接、残句和损坏词语，包括批次首尾。原文确有重复或脚本表达不同但含义准确时保留。
- 核对说话人、人物身份、叙述视角、事实、时序、因果、否定、不确定性与信息公开顺序。第一人称叙述者的回忆、心理和判断保留旁白，实际发言用对白；修正明确的归属错误，保留合理的心理表达。引用中的台词保持引用身份，复述回忆场景（effect=memory）与 `@effect next memory` 里按原说话人标注的过去原话除外；已有可用原注保留实际文字和对应关系。注解未完整识别、未关联或未提供内容时允许无注解回退，不为补齐注解要求额外补丁；正文自身的遗漏或错误仍按来源核对。
- 修正指令、字段、ID、来源、转义与结构错误。人物沿用稳定身份和初始声明，公开名在原文揭示处更新；来源对应真实原文。已有分块及 document 全文保持；仅在结构无效或造成明确的场景／归属错误时局部修正，不按字数或阅读节奏重新拆句。
- 每项补丁只改消除该错误所需的部分，保留正确措辞、标点和内容。复核不做润色、文风调整或美术评价。依据不足时保留原稿，在 notes 指出疑点；没有确定错误时 patches 为空。

## 修补时使用的语法

- 保持 `@vn 0.10`、书籍／章节 ID 及正确的块 ID。声明在章节之前；块内依次写块头、@source、所需状态与正文。实体引用须有稿内声明，沿用所给登记中的 ID、初始称呼与颜色；每个实际内容块至少一个正文单元。
- ID 以英文字母开头，其余只含英文字母、数字、_、-；none 为保留值，v0.7 起 guest 也不作实体 ID。字符串属性用双引号，内部双引号写 \"，反斜杠写 \\，属性不跨行。
- @character ID label="初始称呼"；v0.2 起可带 color="#RRGGBB"。@location ID label="空间名"。@chapter ID title="章名"。@scene ID 可带 loc、time、pov、effect，v0.3 起可带 title；@narration 只带可选 effect；@document 可带 style=message／verse。effect 为 none／memory／dream。
- @source 来源ID[,来源ID2...] 在当前块持续有效，换块重新写，编号前缀与前导零逐字匹配。@reveal 人物ID 可带 label="新名" 或已有 profile 引用；@effect next memory／dream／none 的状态应有对应正文。
- 旁白直接写文字；对白 [人物ID] 台词；心声 [人物ID|心声] 内容；标签不带表情。v0.7 起支持 [guest|当前称呼]，也可带心声；guest 不作实体声明。
- v0.3 起，{{人物ID|当时称呼}} 关联人物；地点、物品、组织及 guest 的提及用普通文字。v0.3—0.4 提及前须已 reveal；v0.5 起首次对白、心声和人物提及所在的正文自动公开，pov 和普通姓名文字不公开。v0.1—0.2 的双花括号仍是字面文字。
- v0.6 起，@document ID → @source（整份来源）→ 可选 @reveal → @text → 引用全文 → @enddocument。全文内人物链接按本稿版本处理，原书注解链接自 v0.8 起；其余像指令、标签和注释的文字按原文保留，不插入分页或状态。
- v0.8 的注解锚点为 {{note:注解ID|词语}}，与人物重合时为 {{人物ID|称呼|note:注解ID}}。定义是全文区外的独立 // @vn-note {"id":"注解ID","text":"原注文字","source":["来源ID"]}，使用单行 JSON。定义未被引用时保留记录，不强求补关联；引用缺少定义时按普通文字显示，人物关联仍保留。// @vn-transition source=来源ID[,来源ID2...] 放在分隔符对应位置、下一块之前。
- 普通正文行首的 @、[、//、反斜杠用前置反斜杠表示字面文字；v0.3 起字面 {{ 写作 \{{。document 全文内的这些行首通常照写，只有字面 {{ 和独占一行的 @enddocument 分别写作 \{{、\@enddocument。
- 来源去向为 // @source-use 来源ID kind=chapter target=章节ID reason="理由"，或 kind=annotation／excluded（后两者不带 target）。去向记录不与正文或其他去向重复；内嵌原注的来源可与正文共用，独立注解通过真实注解来源覆盖。原文分隔来源由 @vn-transition 覆盖。
- 已有 @profile、人物资料容器和导演记录在本轮保留；涉及其内容或位置关联的疑点写入 notes。补丁只针对本批正文，不借修补提前公开、补造证据或改变协议版本。
