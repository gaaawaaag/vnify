# C3 · 作品语言

开发编辑模块。标记之间是发送给模型的文字；标记和本文标题不发送。

lang.output 放在各配方与导演规则的开头。简体中文作品用这里的空片段，不多发文字；其他语言与繁体中文的作品用同名语言版本（如 `lang.output.en`、`lang.output.zh-Hant`），由 `scripts/prompts.mjs --lang` 与导演 packet 按作品语言选取。

## lang.output.en

<!-- prompt:lang.output.en -->
# 作品语言：英文

原文是英文，本作品的产物一律用英文书写并保留原文措辞：正文的旁白、台词与心声，章节标题，人物与地点的称呼（label），人物资料与世界词条，登记表里的标题、称呼与概括，导演结果里给读者看的 name。原文照抄或改写，不翻译成中文，也不写成中英混排。

- 规则写“中文名”“简短中文名”的字段，本作品写简短的英文名称；画面描述（prompt）照常用英文。
- 原文没有给出名字的第一人称叙述者，称呼写 Narrator。
- 规则按“字”计的长度，本作品按英文单词计，例如“两到六个字”即二到六个单词。
- 规则中的中文示例只示意做法；英文正文沿用原文的英文标点和引号样式。
- 给制作者看的说明、核对记录和 notes 可以用中文。


<!-- /prompt -->

## lang.output.ja

<!-- prompt:lang.output.ja -->
# 作品语言：日文

原文是日文，本作品的产物一律用日文书写并保留原文措辞：正文的旁白、台词与心声，章节标题，人物与地点的称呼（label），人物资料与世界词条，登记表里的标题、称呼与概括，导演结果里给读者看的 name。原文照抄或改写，不翻译成中文，也不写成中日混排。

- 规则写“中文名”“简短中文名”的字段，本作品写简短的日文名称；画面描述（prompt）照常用英文。
- 汉字、假名的写法与送假名照原文，不改成简体字或中文用字；原文是旧字旧假名时照旧。
- 原文的读音标记（振假名）在编号时已去掉，不自行补注读音。
- 原文没有给出名字的第一人称叙述者，称呼写原文的自称（私、僕、俺等）；原文没有自称时写“語り手”。
- 规则里对“他说”“她问道”一类说话提示的处理，同样用于「と彼は言った」「と訊いた」等日文说话提示。
- 规则中的中文示例只示意做法；日文正文沿用原文的标点和引号样式（「」『』）。
- 行末标点照原文：台词在引号前没有句号（「オオ、気味の悪い」）、书信称呼以读点结尾（奥様、）时原样保留，不为满足句末标点的要求补“。”“！”，也不改标点。
- 给制作者看的说明、核对记录和 notes 可以用中文。

## lang.output.zh-Hant

<!-- prompt:lang.output.zh-Hant -->
# 作品语言：繁体中文

原文是繁体中文，本作品的产物一律用繁体字书写并保留原文用字：正文的旁白、台词与心声，章节标题，人物与地点的称呼（label），人物资料与世界词条，登记表里的标题、称呼与概括，导演结果里给读者看的 name。原文照抄或改写，不转成简体字，也不简繁混写。

- 规则写“中文名”“简短中文名”的字段，本作品写繁体字；画面描述（prompt）照常用英文。
- 异体字与地区用词照原文（裡／裏、着／著、台／臺等），不统一改写。
- 格式指令、属性名与标签关键字照规则原样写，如心声标签写 `[ID|心声]`，不改成繁体字；正文、称呼与引号里的值用繁体。
- 规则中的简体示例只示意做法；繁体正文沿用原文的标点和引号样式（「」『』或“”）。
- 给制作者看的说明、核对记录和 notes 可以用简体中文。
