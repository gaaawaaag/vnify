## 世界词条
本次另为作品独有的名词写简短词条，帮助读者想起“这是什么”。只收作品中虚构或特有、读者隔章再见可能需要提醒的名词，例如种族、组织、制度、技术、物品、历法、概念；现实中通行的事物、人物和一般地名不收，地点不必逐一写词条；望文即可明白意思的说法也不收。收录宁缺毋滥，没有合适的名词时不写。
每个词条全书只登记一次，此前已保存的词条不再重复。释义一两句，具体说清它是什么，可以用本次范围内的正文信息帮助读者理解；不写剧情经过，不透露谜底和关键反转。

label 和 aliases 使用正文中逐字出现的写法，各至少两个字，不与人物名或称呼相同；没有其他写法时省略 aliases。@term 不需要 @after。
