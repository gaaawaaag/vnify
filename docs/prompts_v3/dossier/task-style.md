## dossier10.task

<!-- prompt:dossier10.task -->
# 渐进人物资料
根据已验收正文、首次公开依据和此前资料，生成随阅读进度解锁的人物资料，帮助读者想起“这个人是谁”。逐块处理整个目标范围，只写新增或需要更新的信息；跨章合批也按各块当时的信息写。
补齐待补名单中已公开人物的一句话简介。简介写“这个人是谁”：身份、职业、所属、与主要人物的基本关系等稳定信息，可以笼统，例如“安槻大学二年级生”“主角的学长”；不写本章做了什么、剧情经过或推理过程。简介简洁、略带俏皮，详情使用便于查阅的短句，保留自称、误认、传闻及未证实等限定。
返回完整的本次增量纯文本，首行 @dossier 2，不加围栏或解释。已保存事件无需重发；修复时保留本次草稿的正确内容。无待补或新增更新时只返回首行。


<!-- /prompt -->
