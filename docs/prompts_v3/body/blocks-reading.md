### 2. 章节与内容块

- `@chapter 章节ID title="章节名"`
- `@scene 块ID [loc=地点ID] [time="时段"] [pov=人物ID/none] [effect=memory/dream]`
  - 空间地点或时间发生实质转移时才新建 scene；同地连续的行动、交谈不拆场。
  - time 只写原文交代的时段，如清晨、上午、傍晚、深夜；“次日”“三年后”等相对日期留在正文。原文没有交代时段时省略。
  - loc 引用表内地点；原文交代的地点不在表内时，按本批规则新增地点。原文未交代当前地点时省略 loc，表示沿用前一个现实场景的地点，不从表中猜测。
- `@narration 块ID [effect=memory/dream]`：不在具体场面中的叙述，例如时间过渡（“三年后……”）、议论、无确定地点的跨时空描写、较长的引文。具体场景里的心理和议论留在 scene 内，不为此另开块。
- `@document 块ID [style=message/verse]`：需要整体呈现的引用。信件、邮件、新闻、公告、日记等用默认的 message（可省略）；题记、献词、诗歌和短引文用 `style=verse`。按引用是否需要整体呈现来选择，不按字数。引用中的对白保留原有引号和归属提示。
- 中间穿插叙述／人物反应时，按原文顺序分开处理，引用部分用 document，其余按所在场面用 scene 或 narration。
- scene／narration 为回忆时使用 `effect=memory`，为梦境时使用 `effect=dream`。回到现实时间线时建立普通块。
- 人物在台词中或旁白在叙述中较详细地复述过去的场面与对话（有具体的经过，并有两句以上的原话或往来对白）时，从复述开始处建立 `effect=memory` 的 scene 呈现这段过去：复述者讲述经过的话仍是复述者的对白（旁白复述时仍为旁白），其中引述的各人原话改标为原说话人的对白；原说话人在复述时读者还不知道身份时用 `[guest|复述中的称呼]`。原文交代了过去的地点时写 loc，否则省略。复述者的插话、评论和对听者说的话回到当下，复述结束后建立普通块，回到复述前的同一场面时省略 loc。
- 旁白或人物台词只引述某人过去说过的一两句原话时，不另建块：原话写成原说话人的对白，每句前写 `@effect next memory`。只是提及、概括或转述大意时，保持为复述者的台词或旁白。
- 每个内容块按这个顺序输出：`@scene／@narration／@document` → `@source` → 本块需要的其他状态指令 → 正文。先建立新块，再为新块声明来源。每个块至少包含一个正文单元。
- document 在块头用一条 `@source` 列出整份引用的所有来源；需要改名时在正文前用 `@reveal`。然后写独立 `@text`，按原貌输出引用内容，最后用独立 `@enddocument` 结束。一份 document 整体为一个阅读单元，保留措辞、标点、段落、换行、空行、已有标题／称呼／落款，不套用逐句拆分／精修或句末规则；verse 同样保留原有分行与缩进，不为居中另加空格。
- `@text` 与 `@enddocument` 之间不解释对白标签、指令或注释；原文中的 `[署名]`、邮件地址、`//` 等照写。人物提及仍可用 `{{人物ID|原文称呼}}`，全文显示时统一公开，不代表在场。字面 `{{` 写作 `\{{`；原文独占一行的 `@enddocument` 写作 `\@enddocument`。不要在全文内部插入 @source、@reveal 或分页记录；原文内部的符号／分隔行保留为资料内容。
