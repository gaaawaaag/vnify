# B4 · body/sources-notes-transitions

开发编辑模块。标记之间是发送给模型的文字；标记和本文标题不发送。⟪字段⟫ 由程序填入，不执行代码。来源和字段见 manifest.json。

## body.annotations

<!-- prompt:body.annotations -->
### 原书注解

- 能确认内容和对应关系时，将正文中的（注：……）、（译者注：……）、译注／作者注／编者注，以及编号对应的页末、章末、篇末注解转换格式。识别括号的实际用途，非注解目的的括号仍保留在正文中。
- 按原文语义判断被解释的词语或短语范围。在该次出现处写 `{{note:注解ID|词语或短语}}`；同一个词的其他出现不自动加注。人物称呼同时需要人物关联时写 `{{人物ID|称呼|note:注解ID}}`，不嵌套标记。
- 用独立单行记录保存注解：`// @vn-note {"id":"b001_n01","text":"译者注：原文注解内容。","source":["p000010"]}`。这是 JSON：原注换行写 `\n`，引号和反斜杠按 JSON 转义。保留注解原文措辞、段落和作者／译者署名；作为索引的编号省略。注解 ID 使用本批前缀，每条定义一次。
- 记录放在本批章节头之后，非正文。scene、narration、document 的正文均可使用注解标记。注解 text 是纯文本，内部不解析人物、指令或其他注解。
- 内嵌注解从句中移出后，正文保留原来的被解释文字并加链接；正文 @source 与注解 source 可以相同。已转换的独立注解来源用记录的 source 覆盖。若本批只是先前／后续正文所引用的注解原文，使用 `// @source-use 来源ID kind=annotation reason="原注已随对应正文保存／由对应正文批次提取"`。
- 注解较多、未能完整识别或无法可靠关联时，允许输出无注解链接的正文，不要求补齐全部注解。保留正文的词语、事实和信息顺序；能确认是独立原注的来源可用 `// @source-use 来源ID kind=annotation reason="原注未能可靠关联，按无注解内容处理"` 登记并省略注解内容。不能确认是否属于原注的段落仍保留为可读正文。
- 编号有可能逐页或逐章重置，按章节、页面及上下文对应，不能仅凭相同数字全书合并。跨批注解使用提供的原书注解材料，source 指向真实注解来源；保留的注解采用原文内容，不猜测关联或补造释义。

## body.transitions

<!-- prompt:body.transitions -->
### 5. 原文分隔过渡

- 原文中独占一行、用来隔开上下文的 `*`、`***`、`————` 等符号，转换为独立演出记录：`// @vn-transition source=来源ID[,来源ID2...]`。该记录放在前段正文之后、下一内容块之前；下一段即使仍在同一地点，也建立新块并复写场景属性。保留原文的空间、时间及信息顺序。
- 全文末尾无后文的纯装饰用 excluded 登记。


<!-- /prompt -->

## body.sources

<!-- prompt:body.sources -->
### 2. **来源去向匹配**：

- 所有目标编号必须出现在正文 `@source` 或注解记录的 source 中，或者作为以下单行注释登记：
  - `// @source-use 来源ID kind=chapter target=章节ID reason="整段确属章节标题"`
  - `// @source-use 来源ID kind=annotation reason="明确的原书注释/脚注"`
  - `// @source-use 来源ID kind=excluded reason="具体书外材料或纯标题／装饰的排除理由"`
- 书外说明材料用 excluded 登记：译者序、作者序、编辑导读、创作说明、作者后记、卷首人物表、版权出版信息等。故事内序幕、尾声、人物介绍、叙事附录保留，按实际内容功能判断。
- 本批只有书外说明、纯书名／卷章标题或装饰而无可读正文时，仍输出 @vn、@book、本批 @chapter 和逐来源 source-use，省略实体与内容块；纯章标题用 chapter 登记，其余用 excluded。题记、献词、引文并非空章。
- 一个编号来源同时含书外说明与故事正文时，保留其故事正文并用 @source 引用该来源。
- 题记、献词、诗歌、短引文写成 `@document 块ID style=verse` 的全文并关联 `@source`。


<!-- /prompt -->
