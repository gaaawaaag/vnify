### 3. scene／narration 正文行格式（每行为一个点击单元）

- **逐句分屏**：每句独占正文行，每行单独一屏。
- 各句分别关联自己的 `@source`，同来源可沿用；一句跨多个来源时列出全部来源。状态指令作用于下一正文单元。
- **旁白**：直接写正文。
- **对白**：`[人物ID] 台词`
- **非实体对白**：未登记的临时搭话者、背景群众使用 `[guest|当前已知称呼] 台词`，如 `[guest|店员] 欢迎光临。`；心声写作 `[guest|称呼|心声]`；仅称呼可含空格，不含 `|` 或方括号。重要人物按新增实体规则声明并引用 ID。
- **心声**：`[人物ID|心声] 心理活动`
- 第一人称叙事中，叙述者“我”的感受、回忆、自问和内心判断直接写为普通旁白，旁白本身承载其心声，不另加 `[ID|心声]`。实际说出口的话仍用对白标签；第三人称叙事或明确嵌入的其他人物内心语言，按风格处理。
- 人物标签只写说话人和可选的心声标记，神情与动作写成正文。实体 ID 和心声标记不加空格，guest 称呼可保留必要空格，不使用 `[none]`。
- **行内人物提及**：用表内或本批新增人物的 ID 写作 `{{人物ID|原文称呼}}`，用于姓名、称谓、绰号等称呼；“他”“她”“我”等代词照写，不加标记。地点、物品、组织和非实体人物保持普通文字，例如 `{{lin|林舟}}走向旧车站。`；地点 ID 用于场景 `loc=`。字面 `{{` 写作 `\{{`。
