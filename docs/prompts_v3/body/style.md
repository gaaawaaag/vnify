# B5 · body/style

开发编辑模块。标记之间是发送给模型的文字；标记和本文标题不发送。⟪字段⟫ 由程序填入，不执行代码。来源和字段见 manifest.json。

精修（配方 `style`）＝ style.base＋style.tags＋style.thoughts；精修-删 tag（配方 `style-no-tags`）＝ style.base＋style.no-tags＋style.thoughts，只有说话引导的处理不同。原文（配方 `style-original`）＝ style.original，单独成篇：正文照录原文，对白与心理描写不改写，用于对话很少或非小说的文本。

带 `.en` 的片段是英文作品的语言版本，按 `--lang en` 替换同名片段；规则与中文版一一对应，只改标点、引号、说话提示和示例。

## style.base

<!-- prompt:style.base -->
# 文学与改写规范（视觉小说文风与节奏）

### 1. 忠实与边界

- 保留原文事件、因果、动作、台词、人物动机、伏笔，以及“他以为/据说/似乎”等认知限定。
- 除非另有要求，视角严格对应原文。
- 原文中能从上下文确定原意的输入或识别错字（形近、同音的错字、漏字、多字）直接订正；拿不准的照录原文。

### 2. 点击单元与节奏控制
- document 保留引用的原貌：措辞、标点、段落、换行、空行、标题、称呼与落款；以下叙事拆句、标点精修、对白及心声改写规则只作用于 scene／narration，不改写 document 内容。
- 逐句分屏，连用的句末标点（如“？！”“……？”）属于同一句，不拆开。
- 引文保留原有身份、完整内容和信息顺序；其中的对白保留引号和归属提示。
- **标点规范**：每个单元必须以句号、问号、感叹号、省略号、破折号或波浪号（。！？……——～）收束，可后接闭合引号或括号。不以逗号、冒号或分号作为正文行结尾。
- 题记、献词、引文等非叙事材料允许保留原有无句末标点的形式。

## style.tags

<!-- prompt:style.tags -->

### 3. 说话引导与对白去引号
- **剥离外层引号**：确定归属并加上 `[ID]` 标签后，**必须删除**包裹整句台词的外层双引号（“ ”）或直角引号（「 」）；台词内部引述保留。
- **纯归属提示删除**：纯粹的“他说 / 她问 / 某某答道”直接删除。
- **信息性引导转独立陈述**：带有动作、神态、声音特征的说话引导，写成完整前置动作：
  - *例*：“听见门外的声响，X问：‘谁在外面？’”
    → `X听见门外的声响。` 换行 `[X] 谁在外面？`
  - *例*：“Y突然腼腆地说道：‘没有。’”
    → `Y突然腼腆起来。` 换行 `[Y] 没有。`
- 引导中交代的时间、场合或先后（如“稍顷”“分手时”）同样写成前置陈述，或并入相邻叙述。

## style.no-tags

<!-- prompt:style.no-tags -->

### 3. 说话引导与对白去引号
- **剥离外层引号**：确定归属并加上 `[ID]` 标签后，**必须删除**包裹整句台词的外层双引号（“ ”）或直角引号（「 」）；台词内部引述保留。
- **说话提示整体删除**：只交代谁在说、怎样说的引导，连同修饰说话的词语一起删除，如“他说”“她问”“某某低声说”“某某冷冷地说道”“某某腼腆地答道”。语气、音量、神情等说话方式不另写成陈述。
- **动作与解释转独立陈述**：引导中伴随的动作，交代的时间、场合或先后（如“稍顷”“分手时”），以及说话的意图、所回应的事等解释性内容，写成完整前置陈述或并入相邻叙述，下一单元保留台词：
  - *例*：“X低声说：‘走吧。’”
    → `[X] 走吧。`
  - *例*：“听见门外的声响，X紧张地问：‘谁在外面？’”
    → `X听见门外的声响。` 换行 `[X] 谁在外面？`
  - *例*：“Y突然腼腆地说道：‘没有。’”
    → `[Y] 没有。`
  - *例*：“Z想岔开话题，放下杯子说：‘先吃饭吧。’”
    → `Z想岔开话题，放下杯子。` 换行 `[Z] 先吃饭吧。`

## style.thoughts

<!-- prompt:style.thoughts -->

### 4. 心声转换

- 先判断叙述视角。第一人称叙事中，“我”的心理、感受、回忆、自问和判断保留为普通旁白，不另标心声。
- 其余情况下明确属于某人物的内心语言使用 `[ID|心声]`。
- 归属明确的第三人称心理描写可转为该人物的心声，人称转为无人称或第一人称，保留心理信息及其认知边界。
- 叙述者概括、归属不明或多人心理，保留为普通旁白。

## style.original

<!-- prompt:style.original -->
# 文学与改写规范（原文）

### 1. 照录原文

- scene／narration 的每一行都是原文的一句，照抄原文措辞、标点与顺序，不增删、不润色；document 保留引用的原貌。
- 对白与心理描写原样留在旁白里：保留引号、“他说”一类说话提示与“他想”一类心理叙述，不加 `[ID]`／`[ID|心声]` 标签，不拆分或改写句子。
- 原文中能从上下文确定原意的错字（形近、同音的错字、漏字、多字）订正后写成改写行；拿不准的照录。原书注解按注解规则移出并加链接。
- 题记、引文、诗歌、信件、表格式的条目等成篇引用写成 document。

### 2. 人物提及与分块

- 用 `@alias` 列出本批中始终指同一人物的称呼，照抄行由工具加上人物提及；泛称和指代不唯一的叫法不列入，原样保留。
- 按原文的地点、时间与话题变化分块：发生在具体地点的段落写 scene 并标出 `loc`，议论、说明、概述与跨时空的叙述写 narration。
- 整段照录写段落号或段落号范围，如 `5` 或 `5-12`：工具把这些段落逐句展开为旁白，每句一行，冒号或逗号后接引语的句子与引语保持在同一行。范围不跨块，不包含章节标题行、分隔行、要写成 document 的段落和要改写的句子所在的段落；这些段落照简写稿规则逐句写。
