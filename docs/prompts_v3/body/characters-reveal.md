# B3 · body/characters-reveal

开发编辑模块。标记之间是发送给模型的文字；标记和本文标题不发送。⟪字段⟫ 由程序填入，不执行代码。来源和字段见 manifest.json。

## body.entities

<!-- prompt:body.entities -->

### 1. 书籍与新增实体声明（置于章节之前）

- `@book 书籍ID title="书名"`
- `@character 人物ID label="初始称呼" color="#RRGGBB"`：新增人物使用初次出现时已知的称呼，并选定固定颜色。
- `@location 地点ID label="地点名称"`：新增地点使用当时已知的空间名，可用“宅邸·书房”消歧。
- 已给出的人物与地点直接引用其 ID。实体表为空时，为本批使用的人物与地点填写声明。

## body.states

<!-- prompt:body.states -->
### 4. 状态指令

- `@source 来源ID[,来源ID2...]`：放在所属内容块的起始指令之后、对应正文之前。同块内持续生效，换来源时更新；切换内容块后重新声明，即使新旧块使用同一个来源。来源属于正文单元，不是场景属性。来源 ID 必须逐字精确匹配输入编号（包含前导零）。
- `@reveal 人物ID [label="新名"]`：在真正更新公开名称或特殊提前公开时使用；首次对白、心声或行内人物提及自动公开，无需先写 reveal；名称变更时使用 `label=`。指令放在内容块内、对应正文之前。
- 本转换任务使用上述指令集。
