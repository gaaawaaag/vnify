# 宿主与子代理

## 分档

- **创作档**：资料整理、规划、写手、复核。用宿主可用的最强写作模型。
- **执行档**：vn-convert（正文转换、人物资料）、vn-director（导演提示词）。用较便宜、能稳定遵守格式的模型；工具校验兜底，校验反复失败时改用创作档重做该批。

用户指定了模型时按用户的。每个阶段实际使用的模型记入 `notes.md`。

## Claude Code

- 子代理用 Agent 工具启动，`model` 参数可选 `opus`、`sonnet`、`haiku` 等；创作档用当前最强的写作模型，执行档用 `sonnet`。省略时继承主会话模型。
- 子代理不继承你的对话，提示词里要写清任务，并给出执笔包全文或它可读取的文件路径。写手只给执笔包，复核给 review.md 所列文件。
- 项目可在 `.claude/agents/*.md` 定义固定角色，在 frontmatter 写 `model`；没有定义时直接用 Agent 工具传参即可。
- 转换的多批正文和导演各章可以并发交给执行档子代理；执笔不并发。

## 其他宿主

- 支持子代理并能指定模型：按上面的分档对应。
- 支持子代理但不能指定模型：照常用子代理，以保持写手与规划意图隔离。
- 不支持子代理：全部由当前会话完成。按章节顺序执笔时只依据执笔包内容写作，并在 `notes.md` 记录“写手隔离未生效”。
