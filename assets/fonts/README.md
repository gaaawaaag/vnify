# 标题字体

章节与地点标题使用 InkPantherType / Alexander Tseng 的 Cheese Foam Oolong Song（芝士奶盖乌龙宋）轻便版 Bold，官方版本 V0.103，字体文件保持原样。轻便版缺失的繁体、生僻字由现有 Georgia / SimSun 等字体回退。

- [官方仓库](https://github.com/InkPantherType/CheeseFoamOolongSong)
- [V0.103 发布与原文件](https://github.com/InkPantherType/CheeseFoamOolongSong/releases/tag/V0.103)
- [随附 SIL OFL 1.1 许可与版权](OFL.txt)

字体约 12.2 MB，本地随软件分发，阅读时不请求外部字体服务。正文和一般界面字体不变，暂无用户字体选择入口。

# 英文作品字体

打开英文作品（`@book lang=en`）时，正文、书名与标题用 Crimson Pro，界面用 Inter；两者均为可变字体，原样随附，未改写。

- Crimson Pro（CrimsonPro-VariableFont_wght.ttf，Version 1.003）：Copyright 2018 The Crimson Pro Project Authors (https://github.com/Fonthausen/CrimsonPro)，SIL OFL 1.1，见 [crimson-pro-OFL.txt](crimson-pro-OFL.txt)
- Inter（Inter-VariableFont_opsz-wght.ttf，Version 4.001）：Copyright 2016 The Inter Project Authors (https://github.com/rsms/inter)，SIL OFL 1.1，见 [inter-OFL.txt](inter-OFL.txt)

# Soda 主题字体

Soda 主题（styles/themes/soda/fonts）使用寒蝉半圆体（ChillRoundM，Version 1.800），基于 Zen Maru Gothic 调整，由 ZeoSeven 的 cn-font-split 切分为 WOFF2 分片，按 unicode-range 按需加载。

- Copyright 2021 The Zen Maru Gothic Authors (https://github.com/googlefonts/zen-marugothic)；寒蝉半圆体由 ChillType / Warren 调整（https://github.com/Warren2060/ChillRound）
- 许可：SIL Open Font License 1.1，条文同本目录 [OFL.txt](OFL.txt)

# 缮本 Folio 主题字体

Folio 主题（styles/themes/folio/fonts）的三套字体来自 ZeoSeven FontsAPI，WOFF2 分片未改写，按 unicode-range 按需加载；只收录含基础字符、基本汉字或全角符号的分片，缺字按字体链回退。

- 正文：屏显臻宋（Clear Han Serif Regular），SIL OFL 1.1，见 [folio-OFL.txt](folio-OFL.txt)
